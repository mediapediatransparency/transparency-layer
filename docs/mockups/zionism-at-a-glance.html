How this is measured: researchers matched Twitter users to US voter records, used the records to estimate each person's party, and counted, for each website, how many Democrats and how many Republicans shared links to it. The count treats both parties as the same size, so a website shared equally by both comes out 50–50 (the dashed line). It describes who shares a website, not what the website says.

What it covers: only websites have this measure. Books and journals do not, so these bars describe 12 of every 100 footnotes in this article; the other 88 are not counted.
