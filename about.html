About

Transparency Layer for Wikipedia is an independent, non-commercial project that shows how Wikipedia articles came to say what they say.

Status

This is an early prototype. Articles are being added in batches. Figures and wording may change as the method is refined; every change to the code is public.

Independence

The project is not affiliated with Wikipedia or the Wikimedia Foundation and does not edit Wikipedia. It is published under a project name, so attention stays on the evidence rather than on any person.

Checking it yourself

All code and data are public in the project repository. Anyone can rerun the analysis and should get identical results. Corrections are welcome: open an issue with a link to the figure and the evidence.
