Look up an editor

Pick an article to see every editor who wrote at least 1% of it, and what else each of them wrote among the articles we analysed. Or type a pattern ID (the code we use instead of an editor's name).

About these IDs: Editors are shown under pattern IDs (for example K7Q2MX), a keyed code of the account that cannot be reversed by trying account numbers. Pattern IDs are different from the “Editor 1, Editor 2” labels on article pages, and shares are shown as ranges, but an editor listed for an article can often be matched to that article's history, so this is not anonymity. Everything here comes from Wikipedia's public edit histories, which anyone can analyse with their own tools. Being listed says only that the editor's words are in the article; it is not a finding about the editor. Please do not contact, harass or target any editor; concerns about conduct belong in Wikipedia's own processes.

Nothing chosen yet. The overview lists the editors who wrote in the most articles.

Based on the 2,054 articles analysed so far, so an editor's work on other articles is not counted. Share: the range their words make up of the article's current text. Sources: every citation the editor added that is still in an analysed article, described with the same ratings as the Sources page; counts and shares are ranges. The same rules apply to every editor.

Where they edit across Wikipedia is shown for a sample: the 5 registered editors with the most words in each area's analysed articles (92 editors); “–” for everyone else. We take the editor's last 10,000 edits to articles and count how many went to articles in each contentious topic that Wikipedia marks. An edit to an article marked with two topics counts in both. Subjects we chose ourselves (see Which articles) are not counted here yet.
