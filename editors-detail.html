Editors across articles: overview

How the writing of the analysed articles is spread across editors. Each figure counts individual editors. This page shows the data and draws no conclusions from it. To see one article's editors, or one editor, use Look up an editor.

About these IDs: Editors are shown under pattern IDs (for example K7Q2MX), a keyed code of the account that cannot be reversed by trying account numbers. Pattern IDs are different from the “Editor 1, Editor 2” labels on article pages, and shares are shown as ranges, but an editor listed for an article can often be matched to that article's history, so this is not anonymity. Everything here comes from Wikipedia's public edit histories, which anyone can analyse with their own tools. Being listed says only that the editor's words are in the article; it is not a finding about the editor. Please do not contact, harass or target any editor; concerns about conduct belong in Wikipedia's own processes.
