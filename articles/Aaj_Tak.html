Wikipedia's voice in the opening

Each sentence of the opening section checked against Wikipedia's neutrality policy. A sentence is marked (orange edge) when there is evidence it is contested (editors took it out for a day or more and put it back, tagged it as disputed, or argued over it on the talk page; or it uses a word from Wikipedia's own “Words to watch” guideline) and it is stated in Wikipedia's voice, naming no one who holds the view. How the summary rows are calculated. For the sources in scope that have a score s (independent quality, 0 to 1; or audience leaning, −1 to +1), each cited c times: mean per source = (s1 + … + sn) ÷ n, each source counted once; mean per citation = (c1·s1 + … + cn·sn) ÷ (c1 + … + cn), each source counted as often as it is cited. Both cover only scored sources: the share of citations they cover is given beside them. The rows cover every citation in scope, not only the sources listed in the table.
