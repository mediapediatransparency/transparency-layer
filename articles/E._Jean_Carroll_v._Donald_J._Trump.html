For the sources in scope that have a score s (independent quality, 0 to 1; or audience leaning, −1 to +1), each cited c times: mean per source = (s1 + … + sn) ÷ n, each source counted once; mean per citation = (c1·s1 + … + cn·sn) ÷ (c1 + … + cn), each source counted as often as it is cited.
